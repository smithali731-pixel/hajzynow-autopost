# hajzynow-autopost

نشر تلقائي لمنشورات حجزي ناو على انستغرام @hajzynow من خوادم GitHub، والجهاز مطفأ.
انستغرام ينقل كل منشور تلقائيا إلى صفحة فيسبوك حجزي HajzyNow.

- `schedule.json` جدول المنشورات. الوقت مكتوب بتوقيت بغداد (+03:00).
- `media/` الصور والفيديوهات.
- `state.json` ما تم نشره فعلا. لا تعدله يدويا.
- يفحص البرنامج الجدول مرتين كل ساعة، وأي منشور فات موعده بأكثر من 3 ساعات يتجاوزه.

الأسرار المطلوبة في Settings ثم Secrets and variables ثم Actions: `IG_USER_ID` و `IG_TOKEN`.
